# Abdul Khaliq | Contemporary editorial, design B

Four-page static academic website implementing the selected design B: generous outer margins, a prominent natural-color portrait with an asymmetric corner, a single-line name, restrained links, a slim research-interest strip, and one featured publication. Supporting pages share the editorial typography and spacing.

## Preview
Open index.html in a browser. Alternatively, run `python3 -m http.server 8000` inside this folder and visit http://localhost:8000.

## Publish
Upload the files inside this folder to the root of your dr-khaliq.github.io repository, replacing the existing website files, and commit. GitHub Pages needs no build step for this site. The website has not been published by this update.

## Update content
Edit index.html for the biography and featured article; research.html for all 14 research entries; education.html for academic training; teaching.html for course records. site.js holds filters, publication search, citation copying, navigation, and student comments. styles.css contains one consolidated design B stylesheet.

The original external portrait link is retained without grayscale or color alteration. An initials fallback appears if the external image is unavailable. For an independently hosted portrait, add a local image and update its src. Original CV, publication and profile URLs are retained. Fonts have system fallbacks. The sitemap and Google verification file are preserved.

Checks: JavaScript syntax, local links/assets, unique IDs, active navigation, single-line name markup and all 14 research entries passed. Browser visual and interaction verification were unavailable in this environment. Academic claims and external URLs were not independently verified.
