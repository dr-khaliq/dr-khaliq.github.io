# Abdul Khaliq — Academic Website


## Structure

- `index.html` — homepage
- `research.html` — publications, working papers, and reports
- `education.html` — academic training
- `teaching.html` — teaching record and student feedback
- `styles.css` — shared responsive design system
- `site.js` — navigation, filters, citation copy, and teaching feedback controls

The site can be deployed directly from the repository root with GitHub Pages.
