# Abdul Khaliq | Academic website

A restrained four-page academic website with white backgrounds, charcoal text, serif headings, marginal section labels, a small grayscale portrait, and a single-line name. Publication search, category filters, citation copying, teaching filters, and student comments are retained.

## Preview
Open index.html in your browser, or run `python3 -m http.server 8000` inside this folder and visit http://localhost:8000.

## Publish to GitHub Pages
Upload the files inside this folder to the root of your dr-khaliq.github.io repository, replacing the existing files, then commit. No build step is required.

## Edit
- index.html: biography, selected publications, academic links.
- research.html: research entries and citations.
- education.html: academic training.
- teaching.html: course records.
- site.js: interactions and student comments.
- styles.css: typography, layout and mobile styles.

The existing external portrait, CV, publication, profile and font links are retained. The portrait has a neutral initials fallback; fonts fall back to system fonts. Add a local portrait and change its image src in index.html if desired.

Validation: JavaScript syntax, local links/assets, unique IDs, active navigation, single-line name markup, and all 14 research entries checked. Browser visual checks were unavailable in this environment. Academic claims and external URLs were preserved rather than independently verified. The original sitemap and Google verification file are included.
