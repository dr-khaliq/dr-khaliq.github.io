# Abdul Khaliq | Academic website

A responsive, four-page static website for GitHub Pages. Open index.html to preview, or serve this folder with `python3 -m http.server 8000` and visit http://localhost:8000.

## Publish
Upload the files inside this folder to the root of your dr-khaliq.github.io repository, replacing the existing website files. Commit the changes and allow GitHub Pages to finish deploying. No build step or package installation is needed.

## Editing
- index.html: biography, featured work, and academic links.
- research.html: all 14 research entries and citation text. Search and category filters work together.
- education.html: academic training.
- teaching.html: course records and student feedback interface.
- site.js: navigation, search, filters, citations, and the existing student comments.
- styles.css: shared colors, typography, layouts, and responsive styles.

The portrait, CV, fonts, and academic profiles retain their original external URLs. The portrait falls back to a decorative monogram when unavailable. For a self-contained portrait, add a local image and update the image src in index.html. Fonts have local system fallbacks.

Original academic content and external publication links were retained, not independently fact-checked. The Google verification file and sitemap are preserved. HTML local references, IDs, publication count and JavaScript syntax were checked. Browser visual and interaction checks could not run because this environment has no installed browser.
