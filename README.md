# Abdul Khaliq | Contemporary academic website

Four static pages with generous side margins, modern sans-serif typography, natural portrait color, restrained blue accents, and a single-line name. Desktop content is capped at 1000px, providing 220px margins at a 1440px viewport. Smaller screens use responsive gutters.

The homepage has an open publication grid and linked research interests. Research search supports incoming query links, category filters and citation copying. Teaching filters and student comments are retained.

## Preview and publish
Open index.html in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000. Upload the contents of this folder to the root of your dr-khaliq.github.io repository, replacing existing website files, and commit. No build step is needed.

## Edit
Edit the corresponding HTML page for academic content. site.js contains interactions and student comments. styles.css contains responsive styling; its contemporary layout section holds the latest visual styles.

The portrait uses its original external URL without grayscale. The source image is unchanged. An initials fallback appears if it cannot load. For a local portrait, add an image and update its src. Existing CV and academic links remain unchanged. Fonts have system fallbacks.

Validation: JavaScript syntax, local references, unique IDs, active navigation, name markup and all 14 research entries checked. Browser visual and interaction checks were unavailable. Academic facts and external URLs were not independently verified. Original sitemap and Google verification file retained.
